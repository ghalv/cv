\section{Erfaring}

\entry{2024--}
	{AI Engineer}
	{Bouvet}
	{
	\textbf{CV Studio -- Bouvet Konsern (2026--).} Utvikler en AI-basert plattform for å gjøre Bouvet sin samlede CV- og kompetansedata søkbar og anvendelig i nye arbeidsflyter. Løsningen kombinerer strukturert data med embeddings og vektorbasert semantisk søk, slik at kompetanse kan finnes på bakgrunn av kontekst, fremfor bare eksakte nøkkelord. Plattformen brukes til matching av konsulenter mot kundeforespørsler og tilbud. Arbeider på tvers av produktutforming, arkitektur, datamodellering, ingest, søk/scoring og MCP-baserte verktøy som eksponerer data og funksjonalitet for språkmodeller og AI-agenter.
	\newline\vspace{.15cm}
	\textbf{Kantinedata -- AI/data-pilot for Compass Group (2025).} Utviklet en avgrenset pilot som kombinerte data fra en fysisk SensMax 3D-besøkssensor med menydata i PostgreSQL og Databricks. Brukte AI-funksjoner til klassifisering av fritekst og bygget en enkel Streamlit-applikasjon for utforskende analyse. Piloten ble ikke videreført til produksjon.
	\newline\vspace{.15cm}
	\textbf{Equinor -- Subsurface Data Delivery / OSDU (2025).} Utviklet og forvaltet produksjonskritiske Databricks/Spark-pipelines for seismiske data. Migrerte løsninger fra legacy-systemer, harmoniserte data og metadata mot OSDU sine felles domenemodeller og utviklet ny modulær arkitektur med Delta Lake og Unity Catalog. Arbeidet omfattet også datakvalitet, API-eksponering, produksjonsdrift, CI/CD og videreutvikling av løsninger som konsumeres av flere produktteam.
	\newline\vspace{.15cm}
	\textbf{Stangeland Maskin -- ny dataplattform og Fabric-migrasjon (2024--2025).} Hadde en sentral rolle i etableringen av en ny dataplattform i Microsoft Fabric. Designet og implementerte datamodeller, integrasjoner og pipelines for telemetri og driftsdata fra blant annet Cat, Volvo, Hitachi, Scania og Komatsu. Arbeidet omfattet arkitektur, harmonisering av heterogene datakilder, API-integrasjoner, inkrementelle dataflyter, datakvalitet og kuraterte datasett for analyse og operative applikasjoner.
	\newline\vspace{.15cm}
	\textbf{VB Gruppen -- ny dataplattform i Microsoft Fabric (2024--2025).} Deltok sentralt i etableringen av dataplattform og integrasjoner som del av et større digitaliseringsinitiativ. Arbeidet med arkitektur, dataflyter og automatisering mellom blant annet Dynamics 365, Dataverse, SharePoint, Entra, eksterne API-er og Fabric, samt standardisering av utviklings-, deploy- og integrasjonsmønstre.
	\newline\vspace{.15cm}
	\textbf{Altera Infrastructure -- automatisert kjøpsordre (2024--2025).} Designet og utviklet en ende-til-ende løsning for automatisering av kjøpsordrer mellom rederiet og logistikkpartnere. Bygget integrasjonsarkitektur med Azure Data Factory, Azure Functions i Python og partner-API-er/EDI, med validering, berikelse, feil-/retry-håndtering, sporbarhet og CI/CD. Arbeidet krevde både forståelse av forretningsprosessen og oversetting av denne til en robust teknisk løsning.
	}
